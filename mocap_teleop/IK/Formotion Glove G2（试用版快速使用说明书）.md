3. PICO4 Ultra使用通讯线连上电脑，打开PICO4 Ultra，打开 此电脑\\PICO 4 Ultra\\内部共享存储空间，放入解压后的压缩包

## 手套说明

### 手套指示灯

1. 正常电量：绿灯闪烁

2. 低电量：红灯闪烁

3. 充电中：红灯常亮

4. 充电完成：灯光关闭

## 手套标定

- 手套的状态定义

    1. 0：静态检测（开机默认状态）

    2. 1：标定动作1

    3. 2：标定动作2

    4. 3：标定动作3

    5. 4：标定动作4

    6. 5：标定完成

    7. 8 ：收到触发标定的信号，开始标定

1. 主菜单里点击开始动捕，选择Tracker\+手套，点击开始标定手套

2. 四指并拢，拇指张开，手臂伸直，手掌侧放

UDP端口 15000，用于数据传输。原极提供解码示例代码。

UDP端口 51000，用于推送机器信息

|字段名|类型|说明|||||
|---|---|---|---|---|---|---|
|Header1|unit8\_t|0x55|||||
|Header2 |unit8\_t|0xAA|||||
|ID|unit16\_t|0x8001|||||
|Length|unit16\_t|总长|||||
|timestamp|unit64\_t |时间戳 |||||
|Calibration State|uint8\_t|0: Unknown|1: Uncalibrated|2: Calibrating|3: Calibrated||
|Takeover State|uint8\_t|0: Unknown|1: Inactive|2: Active|3: Transitioning|4: EmergencyStopped|
|Control Mode|uint8\_t|0: Unknown|1: Joystick|2: Glove|||

世界坐标系的定义：

原点始终在腰部中心，XYZ轴的正向分别指向标定完成后人体的前左上方向，不随人体转动。

# 常见问题

1. Q : 为什么有的时候手部的实际姿态和动捕人体模型不一致？

    A : 首先确保手套开机后需要静置放在桌子上面10s，扣除零偏。再检查标定动作是否正确

2. Q : 为什么手套出现标定不过的现象

    A : 请先确保动作标准，前面第一个和第二个动作需要保持手部静止，第4个动作需要速度较快的运动，连续10s才行

3. Q : 为什么人移动后动捕数据的频率突然变得很低 

    A :  请注意不要出安全区，出安全区后app会变成后台运行，会导致数据输出异常。可以在pico设置中关闭安全区

4. Q : 为什么标定完成后手臂角度不对，几乎相差180°。
A :  请检查pico的手部的tracker安装，请务必确保pico的tracker的指示灯对着人体，不要相反佩戴
