# 历史归档

这里保留整理前的旧版实现、手工姿态脚本、采集、标定、生成结果和 SDK 安装包。原始文件按 Git blob 原样移动，没有删除采集历史或第三方许可证。

- `IK_legacy/`：原 `IK 2/`。
- `ik_robot_legacy/`：原活动源码下重复嵌套的 `ik_robot/`。
- `manual_robot_setup/`：原 `init_position/` 手工姿态脚本。
- `history_data/`：原 `mocap_teleop/IK/data/` 的已提交历史文件。
- `sdk_packages/`：原手部 SDK 压缩包。

这些是历史快照，其路径和网络配置未按新布局改写。日常运行使用根目录 `run.py`、`app/`、`docs/` 和 `third_party/`。新的录制与日志写入 `app/data/`。
